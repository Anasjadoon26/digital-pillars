# Digital Pillars

A cinematic, interactive digital agency website built around a 3D-native visual system, glassmorphic interfaces, performance-focused motion, and responsive experiences.

**Digital Pillars** helps businesses build and grow their digital presence through paid social advertising, social media growth, web design & development, and digital consulting.

---

## ✦ Experience

The website is designed as an immersive digital environment rather than a conventional agency landing page.

The visual system combines:

* Cinematic 3D environments
* Interactive glassmorphic UI
* Realistic marketing metrics
* Animated charts and counters
* Ambient particles and lighting
* Scroll-driven choreography
* Cursor-reactive interactions
* Magnetic CTAs
* Responsive motion
* Reduced-motion accessibility support

The 3D environment and interface are designed as a single visual system rather than using generated imagery as flat backgrounds.

## Features

### Cinematic Hero

The homepage opens with an interactive 3D environment featuring a central architectural pillar, floating data interfaces, atmospheric motion, and staged content reveals.

### Interactive Data UI

Glassmorphic dashboard panels display realistic marketing metrics, percentages, counters, and miniature charts.

### Scroll Choreography

Sections use GSAP and ScrollTrigger to create:

* Perspective reveals
* Staggered entrances
* Depth-based parallax
* Alternating directional transitions
* Animated counters
* Chart reveals

### Ambient Motion

Subtle environmental animation keeps the experience alive while remaining restrained:

* Particle drift
* Floating interfaces
* Lighting movement
* 3D object motion
* Micro UI animation

### Micro-interactions

Desktop users can interact with:

* Cursor-reactive cards
* Magnetic CTA buttons
* Hover states
* Animated navigation
* Interactive metrics

Cursor-dependent interactions are disabled on touch devices.

### Digital Pillars AI

A lightweight FAQ assistant provides predefined answers through selectable questions rather than an unrestricted chatbot.

Example questions include:

* What services do you offer?
* How do I get started?
* What's your typical turnaround?
* Do you work with small businesses?
* Can you manage Meta advertising?
* Can you build websites?

### Testimonials

A glassmorphic testimonial section presents client feedback in an interactive, responsive layout.

| Technology    | Purpose                                         |
| ------------- | ----------------------------------------------- |
| HTML5         | Semantic structure                              |
| CSS3          | Design system, responsive layout, glassmorphism |
| JavaScript    | Application logic and interactions              |

The implementation intentionally keeps the frontend lightweight and modular.
